# Spotter Freight Rate Assessment

Supervised regression solution that predicts truckload `posted_rate` from load features, then produces:

- `validation_predictions.csv` (12,000 blind loads)
- filled `data/december-chart-inputs.csv` (fixed Lexington → Fort Wayne lane for December 2025)
- `scorer_results/candidate_december.png` via the provided `score.py`

Full methodology is in `Report.docx` and the working notebook `spotter.ipynb`.

## Environment

- Python **3.11** recommended (3.10–3.12 OK)
- Dependencies in `requirements.txt` (`pandas`, `numpy`, `matplotlib`, `scikit-learn`)

```bash
conda create -n spotter python=3.11 -y
conda activate spotter
python -m pip install -r requirements.txt
```

## How to reproduce

1. Install dependencies (see above).
2. Open and run `spotter.ipynb` top to bottom (same working directory as this README).
   - Builds features, compares models on a **time-ordered** holdout, selects the best model
   - Refits on all labeled `train-test` rows
   - Writes `validation_predictions.csv`
   - Fills `predicted_rate` in `data/december-chart-inputs.csv`
   - Runs the scorer at the end of the notebook
3. Or run the scorer manually after predictions exist:

```bash
python score.py --predictions validation_predictions.csv --december-predictions data/december-chart-inputs.csv --output-dir scorer_results
```

Expected scorer output: validated prediction files and `scorer_results/candidate_december.png`.

## Approach (short)

| Step | Choice |
|------|--------|
| Problem | Supervised regression → predict `posted_rate` |
| Split | Time-ordered holdout inside `train-test.csv` (no random shuffle; blind `validation.csv` is future data) |
| Cleaning | Treat negative weights as missing; impute `weight` with train global median; impute `market_index` by train month median |
| Features | Equipment one-hot; calendar features; market / haul engineered features (see notebook) |
| Models compared | LinearRegression, Ridge, RandomForest, HistGradientBoosting |
| Selected model | **HistGradientBoosting** (best time-ordered validation RMSE) |
| Final train | Refit selected model on all labeled rows, then score blind validation + December lane |

December rows do not include `market_index` / `quote_signal`; those are filled from training statistics for inference only so the main model (which uses them on blind validation) can still score the chart. Details and metrics are in `Report.docx`.
